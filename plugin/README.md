# 早期会话状态插件试验（已撤回）

本目录保留早期 MCP 后端、面板、技能和共享解析模块，部分回归测试仍引用这些文件。它没有实现“打开客户端后直接显示在原生输入框内”的目标，已从实际运行配置中撤回。

当前日常状态栏使用项目根目录的 Windows 守护及 `src/renderer.mjs`，不是本目录插件。不要自动安装或重新启用本插件，也不要把其五项面板当作当前六项原生状态栏的验收。

机器专用 `.mcp.json` 由准备脚本生成，不提交；本目录不是可直接使用的本机安装配置。插件仅按绑定 UUID 读取累计用量、保存身份和数字时间，不读取凭据或发送消息。

`tests/plugin-protocol.mjs` 是早期 Work 实机会话验收脚本，要求环境提供有效的 Work 会话 UUID 和累计用量；在 Codex 会话或没有该上下文的环境会失败。它不属于默认28项单元测试，也不用于当前状态栏的完成判定。发布时确认原脚本在当前 Codex 上同样因 Work 假设失败，未放宽断言。

当前项目的使用方法、刷新规则、环境要求及验证边界见 [项目说明](../README.md)。
