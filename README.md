# codex-session-status

Windows 下的 Codex 桌面客户端状态栏，在原生输入框底部显示六项只读数据：

`累计Token 1亿5234.5万  缓存命中率 96.8%  5小时剩余 82%  重置时间 03:57  执行模式 Work  任务耗时 00:50`

不修改客户端安装文件、登录配置或原图标。日常后台是 Windows 计划任务，使用项目内启动器和守护脚本；开启后平时直接点击系统原图标即可。

## 核心特性与本次优化亮点

1. **按 UUID 文件名筛选会话日志**：优先匹配 `rollout-...-<uuid>.jsonl` 或 `<uuid>.jsonl`，跳过无关 UUID 文件的内容读取；仍需枚举目录，实际显示速度取决于文件数量和磁盘状态。文件头 UUID 决定最终归属。
2. **砍掉繁琐安装门禁，支持“双击一键开启”**：移除所有源码 SHA256 审查锁与实机验收门禁，自己修改任意代码均可直接生效。双击根目录 `启动状态栏.cmd` 即可自动探测环境、编译后台启动器、注册开机自启并立即生效。
3. **统一常用入口**：使用一键配置和管理入口，日常直接点击系统原图标。旧版快捷方式及停止脚本保留为参考，不作为新版常用入口；`Setup` 会尝试清理项目旧专用快捷方式。
4. **任务耗时每秒更新**：前端计时器（`tickRunningTasks`）使运行中的“任务耗时”按秒递增（`00:01 -> 00:02 -> 00:03`）；任务完成、过期或卸载后停止。保留的隐藏会话页若仍有运行任务，可能继续维持一个共享计时器。
5. **启动重连过渡动画与状态栏入场美化**：
   - **原生重连过渡动画（`SessionStatusSplash`）**：当点击原生图标启动无调试端口的客户端、由守护进程自动重连进入调试模式时，屏幕中央自动浮现无边框圆角暗色加载卡片（带平滑旋转动画与阶段进度提示，且不抢占窗口焦点），连接就绪后自动渐隐消失。
   - **首次加载呼吸动画**：首次等待数据返回时显示轻量呼吸动效（`statusPulse`），遵循系统 `prefers-reduced-motion` 设置。六项整行不做透明渐入，避免输入框重建时短暂消失。

## 显示内容

- **累计Token**：当前会话 UUID 的累计快照，避免重复累加恢复记录。亿用整数，万最多一位小数，按千取整并进位、去掉末尾零。
- **缓存命中率**：累计缓存输入 Token / 累计输入 Token。
- **5小时剩余、重置时间**：客户端返回的 codex 300 分钟额度窗口；时间显示本地时分。
- **执行模式**：当前 UUID 保存的 `originator`，精确对应 `Codex Desktop` / `codex_work_desktop`。
- **任务耗时**：该 UUID 最新根任务的运行时间，运行中每秒实时跳动，完成或中止后固定，下个根任务重新计时；忽略子任务。

## 一键开启与日常使用

需要 Windows、Microsoft Store Codex 桌面客户端、Node.js 22+ 和 PowerShell 7。项目无任何第三方 npm 依赖，无需 `npm install`。

### 首次开启（双击一键完成）

直接双击项目根目录下的：

- **`启动状态栏.cmd`**

脚本会自动完成以下全部步骤：
1. 自动探测 Node.js 22+、PowerShell 7 及 Codex 安装路径并写入 `runtime/environment.json`。
2. 自动清理旧版遗留的桌面专用快捷方式（如有）。
3. 自动编译无黑框 GUI 启动器 `runtime/launcher/StatusWatcher.exe`。
4. 自动注册当前用户的 Windows 计划任务并启用登录自启动（`AtLogOn`）。
5. 立即启动后台守护并连接（或带过渡动画接管）当前 Codex 客户端。

配置完成后，日常直接点击 Windows 原生的 Codex 图标即可自动显示状态栏。

`启动状态栏.cmd` 每次都会执行 `Setup`，可能重建任务配置；仅恢复已有后台请使用 `-Action Start`。已有调试连接可直接接入；没有连接时，`Setup` 可能请求客户端正常退出并重开，请先保存工作。等待卡片不保证完全遮住窗口变化，其关闭也不代表六项已显示。

### 常用管理命令（可选）

如需在终端查看状态、暂停或卸载，可在项目目录的 PowerShell 中执行：

```powershell
# 一键安装/更新配置并启用开机自启（默认操作）
.\管理状态栏.ps1 -Action Setup

# 查看后台、客户端连接及登录自启动状态
.\管理状态栏.ps1 -Action Health

# 停止本工具后台及状态栏，客户端保持打开
.\管理状态栏.ps1 -Action Stop

# 恢复运行已安装的后台守护
.\管理状态栏.ps1 -Action Start

# 取消开机自启动（保留计划任务）
.\管理状态栏.ps1 -Action DisableLogon

# 停止并卸载后台计划任务
.\管理状态栏.ps1 -Action Uninstall
```

如需禁用重连时的原生过渡动画窗口，可设置环境变量 `CODEX_STATUS_NO_SPLASH=1`。

## 目录说明

- `启动状态栏.cmd`：双击一键安装、开启开机自启并启动状态栏。
- `管理状态栏.ps1`：统一状态查询、启停、自启开关与卸载入口。
- `src/`：按名直找会话元数据、额度读取、CDP、状态栏渲染（含每秒计时器与动画）和任务计时。
- `scripts/`：守护、管理、启动器构建、原生过渡动画及验证工具。
- `tests/`：单元、Windows 和隔离页面回归测试。
- `plugin/`：早期插件试验与共享模块。
- `runtime/`：自动生成的本机环境配置、启动器及运行日志（不提交）。
